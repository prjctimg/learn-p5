Learn P5 is an offline-first Android app for learning p5.js through small coding exercises. Each exercise presents a task with a live canvas preview, a CodeMirror 6 editor with p5.js-aware autocomplete and syntax highlighting, and a context-aware keyboard. Exercises are validated against the p5.js reference and unlock sequentially. The app ships with vendored p5.js and embedded reference data so it works without a network connection.
