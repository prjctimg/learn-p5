# Privacy Policy

Last updated: 2026-11-21

Learn P5 is an offline-first educational app for learning p5.js.

## Data Collection

Learn P5 does not require an account and does not include third-party analytics, advertising SDKs, or tracking SDKs in the app code.

## Data Stored on Device

The app stores learning progress and app-related state locally on your device. This data is used to provide app functionality.

## Permissions and Device Features

- **Notifications (`expo-notifications`)**: Used for app notifications/reminders if enabled by the app. Notification data is handled on-device unless you configure external services.
- **Motion sensors / accelerometer (`expo-sensors`)**: Used for shake detection and related in-app interactions. Sensor data is processed on-device for app functionality.

## Network Access

Core lessons and p5.js reference content are bundled for offline use. Network access may occur only for normal platform/runtime behavior you explicitly trigger, if any.

## Children

Learn P5 is an educational app. If you publish it to app stores, ensure your store declarations match the app’s actual behavior and target audience.

## Changes

If app behavior changes, update this policy and any store disclosures (including Google Play Data Safety) before release.
